Not everything needs to be a dashboard. TwilightSouls takes two birth dates, calculates the real astronomical moon phase for each using actual lunar data, and animates the two moons drifting together across a star field full moon on full moon, or opposites finding each other.

Built in vanilla JavaScript with SVG moons and canvas stars no framework needed.

**Why:** Not every project needs to be a dashboard or an API this one was purely for fun, a creative build outside the usual stack.

**Stack:** Vanilla JavaScript, SVG, Canvas
