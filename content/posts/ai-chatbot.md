An AI-powered chatbot that answers questions over your own documents using retrieval-augmented generation embeddings in a vector database, semantic search to pull relevant context, then a language model to generate the answer.

**Why:** Wanted hands-on experience with a vector database this was the project built specifically to get a real RAG pipeline running around one.

**Stack:** Python, RAG, vector database, semantic search
