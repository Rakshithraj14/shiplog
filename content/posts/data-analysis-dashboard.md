A dashboard for the parts of data analysis that usually happen across five different notebooks: upload a CSV/Excel file, clean it, and get interactive charts and statistical summaries back —packaged to run in Docker.

**Why:** Wanted a way to actually analyze data visually through a dashboard, instead of scrolling back and forth through a notebook to see the same thing.

**Stack:** Python, Docker
