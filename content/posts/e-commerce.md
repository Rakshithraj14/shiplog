A from-scratch e-commerce build covering the parts that actually make a store work: user auth, product listings, cart and checkout, order history, and an admin panel for managing products.

**Why:** Wanted real experience with how a frontend actually calls an API error handling, loading states, and managing user state across a full flow, not just a single form.

**Stack:** TypeScript, Bun
