A rental search frontend for Bangalore, built to talk to a separate backend API for filtering listings by location, BHK, and rent range. Vite proxies API requests in development to sidestep CORS.

**Why:** Started as a scraper against the major rental listing sites in Bangalore pulling name, address, contact details, and rent with this as the frontend for actually browsing what it found.

**Stack:** React 18, TypeScript, Vite, Tailwind CSS, Axios
