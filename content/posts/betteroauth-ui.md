The frontend half of BetterOAuth a React app that handles Google OAuth sign-in via Better Auth and routes authenticated users through React Router. Built fast with Vite.

**Why:** The frontend half of the same exploration as the backend seeing what an OAuth login flow actually looks like from the client side.

**Stack:** React 19, React Router, Better Auth, Vite
