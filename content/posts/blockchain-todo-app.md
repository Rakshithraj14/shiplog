A todo app with a twist: instead of a server and a database, task state is meant to live on the Ethereum blockchain. MetaMask handles the wallet connection, and the UI is wired for create/complete/delete operations against a smart contract (currently running against mock data pending contract deployment).

**Why:** An excuse to explore Web3 wallets, smart contracts, and what "decentralized" actually means for a simple app once you strip away the buzzword.

**Stack:** React 18, Web3.js, Ethereum, Tailwind CSS
